# jayms-tool-data

Tool datasets for the jayms.com Bible Study Tools, one JSON document per tool.

Each file is generated from its markdown source in `~/jayms-tools-alpha/tools/`
by `scripts/md2tooljson.py`. The markdown is the source of truth. Do not
hand-edit the JSON here, it will be overwritten on the next build.

| File | Tool | Entries |
|---|---|---|
| `divine-council-alpha.json` | Divine Council Index (alpha) | 33 |
| `gods-of-the-bible-alpha.json` | The Gods of the Bible (alpha) | 107 |
